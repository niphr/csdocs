# Split one table row's children into cells

Split one table row's children into cells

## Usage

``` r
.split_rd_table_cells(row_children)
```

## Arguments

- row_children:

  One row from
  [`.split_rd_table_rows()`](https://niphr.github.io/csdocs/reference/dot-split_rd_table_rows.md).

## Value

A list of cells, each itself a list of Rd fragments.
