# Write the `README.md` index file

Write the `README.md` index file

## Usage

``` r
.write_index_file(topics, package, version, output_dir)
```

## Arguments

- topics:

  List of parsed topic lists.

- package:

  Package name.

- version:

  Package version.

- output_dir:

  Target directory.

## Value

Path to the written file, invisibly.
