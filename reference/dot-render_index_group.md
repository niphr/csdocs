# Render one group of the index: heading, optional description, table

Render one group of the index: heading, optional description, table

## Usage

``` r
.render_index_group(group)
```

## Arguments

- group:

  A `list(title, desc, topics)` from
  [`.group_index_topics()`](https://niphr.github.io/csdocs/reference/dot-group_index_topics.md).

## Value

A single Markdown string.
