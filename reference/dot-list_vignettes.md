# List the vignette files of one extension in a source package

List the vignette files of one extension in a source package

## Usage

``` r
.list_vignettes(package, ext)
```

## Arguments

- package:

  Path to a package source directory.

- ext:

  File extension without the dot, for example `"Rmd"`.

## Value

A character vector of file names, without the folder.
