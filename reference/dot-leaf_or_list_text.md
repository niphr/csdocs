# Render one Rd child that may be a bare leaf or a list, as inline text

Render one Rd child that may be a bare leaf or a list, as inline text

## Usage

``` r
.leaf_or_list_text(part)
```

## Arguments

- part:

  An Rd child - a bare character leaf (e.g. one argument of
  `\\method{}{}` or `\\tabular{}{}`'s format spec), or a list.

## Value

A string.
